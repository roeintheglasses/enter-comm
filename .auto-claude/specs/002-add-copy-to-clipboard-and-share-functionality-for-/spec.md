# Add copy-to-clipboard and share functionality for group codes

## Overview

Group codes are displayed in the Group tab but users can't easily copy or share them with others. The only option is to manually read and type the code.

## Rationale

The core workflow involves sharing group codes with other riders. Currently users must verbally communicate the code or manually type it elsewhere. A tap-to-copy with visual feedback and a share button would significantly improve this critical user flow.
