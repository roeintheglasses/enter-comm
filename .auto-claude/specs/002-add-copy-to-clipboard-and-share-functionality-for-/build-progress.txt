# Build Progress: Copy-to-Clipboard and Share Functionality for Group Codes

## Feature Overview
Group codes are displayed in the Group tab. This feature adds tap-to-copy with visual feedback and a share button to improve the user experience when sharing group codes with other riders.

## Manual Test Scenarios for QA Verification

### Test Environment Prerequisites
- Android device or emulator running API 24+
- App installed with test group functionality
- User must be part of a group or have a group code

---

### TEST SCENARIO 1: Group Code Badge Tap-to-Copy
**Location:** Group tab > GroupInfoCard > Top-right badge

**Steps:**
1. Navigate to the Group tab
2. Ensure you are part of a group (group code badge should be visible in top-right)
3. Tap on the group code badge

**Expected Results:**
- [ ] Badge shows press animation (slight scale down to 0.95x)
- [ ] After release, badge background changes from dark to green tint
- [ ] Icon animates from copy icon to checkmark icon
- [ ] Haptic feedback is felt (light click)
- [ ] After 1.5 seconds, badge returns to original state
- [ ] Group code is copied to clipboard (verify by pasting elsewhere)

---

### TEST SCENARIO 2: Copy Button in Share Row (Connected to Group)
**Location:** Group tab > GroupInfoCard > Share row (when connected to a full group)

**Steps:**
1. Navigate to the Group tab
2. Ensure you are part of a full MeshGroup
3. Locate the "Share code X to let others join" row
4. Tap the copy button (clipboard icon)

**Expected Results:**
- [ ] Copy button icon animates from clipboard to checkmark
- [ ] Icon tint changes to green
- [ ] Haptic feedback is felt (light click)
- [ ] After 1.5 seconds, icon returns to original state
- [ ] Group code is copied to clipboard

---

### TEST SCENARIO 3: Copy Button in Share Row (Connected by Code Only)
**Location:** Group tab > GroupInfoCard > Share row (when connected by code only)

**Steps:**
1. Navigate to the Group tab
2. Connect to a group using only a code (not a full MeshGroup)
3. Locate the "Share code X to let others join" row
4. Tap the copy button (clipboard icon)

**Expected Results:**
- [ ] Same behavior as Test Scenario 2
- [ ] Both share row locations work identically

---

### TEST SCENARIO 4: Share Button Opens Android Share Sheet
**Location:** Group tab > GroupInfoCard > Share row

**Steps:**
1. Navigate to the Group tab
2. Locate the "Share code X to let others join" row
3. Tap the share button (share icon)

**Expected Results:**
- [ ] Android share sheet opens
- [ ] Chooser title shows "Share group code"
- [ ] Share message contains: "Join my [App Name] group! Enter code: [CODE]"
- [ ] Email apps show subject: "[App Name] Group Code"
- [ ] Haptic feedback is felt when share sheet opens successfully
- [ ] User can select any app to share to

---

### TEST SCENARIO 5: Share via Different Apps
**Location:** Android share sheet

**Steps:**
1. Open share sheet (Test Scenario 4)

- [ ] Social apps receive the formatted message
